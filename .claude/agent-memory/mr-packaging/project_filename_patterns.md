실제로 처리된 파일명 패턴들을 기록한다.

## 확인된 패턴

### [악보바다MR] 접두사 패턴
- 예시: `[악보바다MR]신의 악단 OST-주 예수 나의 산 소망.wav`
- 아티스트: `[악보바다MR]신의 악단 OST`
- 제목: `주 예수 나의 산 소망`
- 아티스트명에 대괄호 `[]` 포함 가능 — 파싱 로직 변경 불필요, 첫 `-` 기준 분리로 정상 처리됨

### 조옮김/Guide 표기 패턴
- `(Guide)` 접미사: 가이드 멜로디 포함 버전
- `(조옮김)` 접미사: 음정 변환 버전
- `(조옮김)(Guide)`: 두 가지 동시 적용
- 이 표기들은 제목 부분에 그대로 포함하여 구분

## 출력 파일명 규칙 적용 결과
- 공백 유지 (CLAUDE.md 규칙): `[악보바다MR]합창-주 예수 나의 산 소망(신의 악단 OST)(혼성4)(베이스).mp3`
- 괄호는 유지: `(Guide)`, `(조옮김)`, `(혼성4부 합창)` 등 제거하지 않음
- mr_packaging_run.py의 parse_filename()에서 `replace(" ", "")` 제거함 (2026-03-17)

**Why:** 악보바다 MR 상품은 동일 곡의 조옮김/가이드 버전을 함께 납품하는 경우가 많아 파일명으로 구분이 필요함.

**How to apply:** 동일 곡의 여러 버전(조옮김, Guide)이 들어올 때 파일명 파싱을 변경하지 않고 그대로 처리하면 됨.
