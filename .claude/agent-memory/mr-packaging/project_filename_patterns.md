### 조옮김/Guide 표기 패턴
- `(Guide)` 접미사: 가이드 멜로디 포함 버전
- `(조옮김)` 접미사: 음정 변환 버전
- `(조옮김)(Guide)`: 두 가지 동시 적용
- 이 표기들은 제목 부분에 그대로 포함하여 구분
